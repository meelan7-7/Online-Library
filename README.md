# 📚 Online Library System

### Github Link


## 🚀 Project Overview
This is a React-based Online Library System built using Vite.  
It allows users to browse books, search books, view details, and add new books.

---

## ⚙️ Technologies Used
- React (Vite)
- React Router DOM
- Redux Toolkit
- CSS

---

## ✨ Features
- 🏠 Home page with categories and popular books
- 📚 Browse books by category
- 🔍 Search books by title or author
- 📖 View detailed information of each book
- ➕ Add new books using a form
- 🔄 State management using Redux
- ❌ 404 Page for invalid routes

---

## 🛠️ How to Run the Project

1. Clone the repository:
   git clone <your-repo-link>

2. Navigate into the project folder:
   cd online-library

3. Install dependencies:
   npm install

4. Start the development server:
   npm run dev

---

## 📌 Notes
- Dummy data is used for books
- Newly added books appear at the top
